# Roadmap

## Tahap 1 — Controller Web
- Dashboard controller
- Daftar perangkat
- Status izin perangkat
- Pengiriman perintah melalui Supabase

## Tahap 2 — Android Target
- Aplikasi Android native
- Registrasi perangkat
- Sinkronisasi status online/offline
- Permintaan izin lokasi, kamera, mikrofon, dan notifikasi

## Tahap 3 — Keamanan
- Supabase Row Level Security
- Hanya pemilik yang dapat mengontrol perangkat
- Semua penggunaan kamera dan mikrofon harus terlihat serta disetujui pengguna
